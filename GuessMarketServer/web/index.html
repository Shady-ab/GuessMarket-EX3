Guess Market server is running

Start the JavaFX client (run.bat in the client folder) to work with the system.

Endpoints

  • POST login (username)
  • POST logout
  • POST upload (multipart, part "file")
  • GET events
  • GET event?id=
  • POST event/open (id), event/close (id, winner), event/buy (id, option, quantity), event/order (id, option, side, quantity, price)
  • GET users
  • GET me?ledgerFrom=
  • POST deposit (amount)
  • GET chat?version= / POST chat (message)
